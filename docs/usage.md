# 六步使用指引

選定一件工作後，依序記錄下表。這份指引不需要安裝工具，也不自動執行任務。

| 步驟 | 應記錄內容 | 自我檢查 |
|---|---|---|
| 看 | 使用者、問題、工作範圍 | 能在 60 秒內說明？ |
| 拆 | 輸入、步驟、判斷、產出 | 沒用過的人能理解？ |
| 定 | 輸入、任務、能力、限制、產出、完成條件 | 知道如何驗收？ |
| 找 | 所需能力、來源、沿用／找現成／自己做 | 每項有明確決定？ |
| 組 | 各項工作、負責者、分工理由 | 為什麼需要 Agent？ |
| 驗 | 實際結果、條件比對、PASS／FAIL | 結果能被檢查？ |

當結果不符合完成條件，回到出錯的步驟修改。資料與需求不清楚時先釐清；現成工具已能穩定完成的部分繼續保留。

公開教學可依圖卡頁序講解；個人與企業團隊可對照此表留下操作成果。本指引沒有附帶實測案例。

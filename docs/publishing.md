## 發布順序

1. 確認 owner、公開或私人，以及文字／圖片／品牌素材的授權範圍與法律權利人。
2. 以完整授權條款更新 LICENSE，同步更新 README 與檢查紀錄。
3. 建立指定名稱的 repository，將本資料夾內的檔案上傳至根目錄；ZIP 檔本身不是 repository 內容。
4. 設定 Description 與 Topics，檢查 README 及八張圖卡顯示。
5. 需要 Release 時，依目標 commit 建立 v1.0.0 tag，使用 release-notes.md；不得覆寫既有 tag。
6. 核對遠端 URL、commit、tag 與 Release 後，才回報發布成功。

本套件尚未建立遠端 repository、tag 或 Release。
